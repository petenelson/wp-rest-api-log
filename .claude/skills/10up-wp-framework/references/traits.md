# Framework Traits Reference

Available traits in the 10up WordPress Framework.

## Module Trait

The core trait for implementing modules. Located at `TenupFramework\Module`.

```php
use TenupFramework\Module;
use TenupFramework\ModuleInterface;

class MyModule implements ModuleInterface {
    use Module;

    public function can_register(): bool {
        return true;
    }

    public function register(): void {
        // Register hooks
    }
}
```

### What Module Trait Provides

- Default `load_order()` method returning 10
- Abstract declarations for `can_register()` and `register()`
- Integration with ModuleInitialization auto-discovery

## GetAssetInfo Trait

Helper for loading compiled asset information from `.asset.php` files generated by 10up-toolkit or wp-scripts.

**Namespace:** `TenupFramework\Assets\GetAssetInfo`

### Basic Usage

```php
use TenupFramework\Module;
use TenupFramework\ModuleInterface;
use TenupFramework\Assets\GetAssetInfo;

class Assets implements ModuleInterface {
    use Module;
    use GetAssetInfo;

    public function can_register(): bool {
        return true;
    }

    public function register(): void {
        // REQUIRED: Call setup_asset_vars() before using get_asset_info()
        $this->setup_asset_vars(
            PLUGIN_PATH . 'dist',    // Path to dist directory
            PLUGIN_VERSION           // Fallback version string
        );

        add_action('wp_enqueue_scripts', [$this, 'enqueue_frontend']);
    }

    public function enqueue_frontend(): void {
        // get_asset_info looks in dist/js/, dist/css/, or dist/blocks/
        $asset = $this->get_asset_info('frontend');

        wp_enqueue_script(
            'my-plugin-frontend',
            PLUGIN_URL . 'dist/js/frontend.js',
            $asset['dependencies'],
            $asset['version'],
            true
        );

        wp_enqueue_style(
            'my-plugin-frontend',
            PLUGIN_URL . 'dist/css/frontend.css',
            [],
            $asset['version']
        );
    }
}
```

### Method Signatures

```php
/**
 * Setup asset variables. MUST be called before get_asset_info().
 *
 * @param string $dist_path        Path to the dist directory
 * @param string $fallback_version Fallback version if asset file not found
 */
public function setup_asset_vars(string $dist_path, string $fallback_version): void

/**
 * Get asset information from compiled .asset.php file.
 *
 * @param string      $slug      Asset slug (filename without extension)
 * @param string|null $attribute Optional: 'version' or 'dependencies'
 *
 * @return array|string Array if no attribute, string if attribute specified
 * @throws RuntimeException If setup_asset_vars() was not called
 */
public function get_asset_info(string $slug, ?string $attribute = null): string|array
```

### Return Value

```php
// Without attribute parameter
$asset = $this->get_asset_info('frontend');
// Returns: [
//     'dependencies' => ['wp-element', 'wp-components', 'wp-blocks'],
//     'version' => '1a2b3c4d5e6f7890',
// ]

// With attribute parameter
$version = $this->get_asset_info('frontend', 'version');
// Returns: '1a2b3c4d5e6f7890'

$deps = $this->get_asset_info('frontend', 'dependencies');
// Returns: ['wp-element', 'wp-components', 'wp-blocks']
```

### Asset File Lookup Order

The trait looks for `.asset.php` files in this order:

1. `{dist_path}/js/{slug}.asset.php`
2. `{dist_path}/css/{slug}.asset.php`
3. `{dist_path}/blocks/{slug}.asset.php`

### Fallback Behavior

If no `.asset.php` file is found, returns:

```php
[
    'dependencies' => [],
    'version' => $fallback_version, // Value from setup_asset_vars()
]
```

### Multiple Assets

```php
public function register(): void {
    $this->setup_asset_vars(PLUGIN_PATH . 'dist', '1.0.0');

    add_action('wp_enqueue_scripts', [$this, 'enqueue_frontend']);
    add_action('admin_enqueue_scripts', [$this, 'enqueue_admin']);
}

public function enqueue_frontend(): void {
    $frontend = $this->get_asset_info('frontend');
    wp_enqueue_script('plugin-frontend', ..., $frontend['dependencies'], $frontend['version']);
}

public function enqueue_admin(): void {
    $admin = $this->get_asset_info('admin');
    wp_enqueue_script('plugin-admin', ..., $admin['dependencies'], $admin['version']);
}
```

## Creating Custom Traits

### Logging Trait

```php
namespace MyPlugin\Traits;

trait Logging {
    /**
     * Log message to debug.log
     */
    protected function log(string $message, string $level = 'info'): void {
        if (!WP_DEBUG_LOG) {
            return;
        }

        $formatted = sprintf(
            '[%s] %s: %s - %s',
            date('Y-m-d H:i:s'),
            strtoupper($level),
            static::class,
            $message
        );

        error_log($formatted);
    }

    protected function log_error(string $message): void {
        $this->log($message, 'error');
    }

    protected function log_debug(string $message): void {
        $this->log($message, 'debug');
    }
}
```

Usage:
```php
class MyModule implements ModuleInterface {
    use Module;
    use \MyPlugin\Traits\Logging;

    public function register(): void {
        $this->log('Module registered');
        add_action('init', [$this, 'init']);
    }

    public function init(): void {
        $this->log_debug('Init action fired');
    }
}
```

### Singleton Trait

```php
namespace MyPlugin\Traits;

trait Singleton {
    private static ?self $instance = null;

    public static function get_instance(): self {
        if (null === self::$instance) {
            self::$instance = new self();
        }
        return self::$instance;
    }

    // Prevent cloning
    private function __clone() {}

    // Prevent unserialization
    public function __wakeup() {
        throw new \Exception('Cannot unserialize singleton');
    }
}
```

### Options Trait

```php
namespace MyPlugin\Traits;

trait Options {
    protected string $option_name = 'my_plugin_options';

    protected function get_options(): array {
        return get_option($this->option_name, $this->get_default_options());
    }

    protected function get_option(string $key, mixed $default = null): mixed {
        $options = $this->get_options();
        return $options[$key] ?? $default;
    }

    protected function update_option(string $key, mixed $value): bool {
        $options = $this->get_options();
        $options[$key] = $value;
        return update_option($this->option_name, $options);
    }

    protected function get_default_options(): array {
        return [
            'feature_enabled' => false,
            'api_key' => '',
            'cache_ttl' => 3600,
        ];
    }
}
```

Usage:
```php
class Settings implements ModuleInterface {
    use Module;
    use \MyPlugin\Traits\Options;

    protected string $option_name = 'my_plugin_settings';

    public function can_register(): bool {
        return true;
    }

    public function register(): void {
        // Access options
        if ($this->get_option('feature_enabled')) {
            add_action('init', [$this, 'init_feature']);
        }
    }

    protected function get_default_options(): array {
        return [
            'feature_enabled' => true,
            'items_per_page' => 10,
        ];
    }
}
```

### Cache Trait

```php
namespace MyPlugin\Traits;

trait Cache {
    protected string $cache_group = 'my_plugin';

    protected function cache_get(string $key): mixed {
        return wp_cache_get($key, $this->cache_group);
    }

    protected function cache_set(string $key, mixed $value, int $expire = 0): bool {
        return wp_cache_set($key, $value, $this->cache_group, $expire);
    }

    protected function cache_delete(string $key): bool {
        return wp_cache_delete($key, $this->cache_group);
    }

    protected function cache_flush(): bool {
        return wp_cache_flush_group($this->cache_group);
    }

    protected function cache_remember(string $key, callable $callback, int $expire = 0): mixed {
        $cached = $this->cache_get($key);

        if (false !== $cached) {
            return $cached;
        }

        $value = $callback();
        $this->cache_set($key, $value, $expire);

        return $value;
    }
}
```

Usage:
```php
class DataService implements ModuleInterface {
    use Module;
    use \MyPlugin\Traits\Cache;

    protected string $cache_group = 'my_plugin_data';

    public function get_expensive_data(): array {
        return $this->cache_remember('expensive_data', function() {
            // Expensive operation
            return $this->fetch_from_api();
        }, HOUR_IN_SECONDS);
    }
}
```

### Transient Trait

```php
namespace MyPlugin\Traits;

trait Transients {
    protected string $transient_prefix = 'my_plugin_';

    protected function transient_get(string $key): mixed {
        return get_transient($this->transient_prefix . $key);
    }

    protected function transient_set(string $key, mixed $value, int $expiration = 0): bool {
        return set_transient($this->transient_prefix . $key, $value, $expiration);
    }

    protected function transient_delete(string $key): bool {
        return delete_transient($this->transient_prefix . $key);
    }

    protected function transient_remember(string $key, callable $callback, int $expiration = 0): mixed {
        $cached = $this->transient_get($key);

        if (false !== $cached) {
            return $cached;
        }

        $value = $callback();
        $this->transient_set($key, $value, $expiration);

        return $value;
    }
}
```

## Combining Traits

```php
class MyModule implements ModuleInterface {
    use Module;
    use \MyPlugin\Traits\Options;
    use \MyPlugin\Traits\Cache;
    use \MyPlugin\Traits\Logging;

    public function can_register(): bool {
        return $this->get_option('enabled', false);
    }

    public function register(): void {
        $this->log('Module registering');
        add_action('init', [$this, 'init']);
    }

    public function init(): void {
        $data = $this->cache_remember('init_data', function() {
            $this->log_debug('Fetching fresh data');
            return $this->fetch_data();
        }, HOUR_IN_SECONDS);
    }
}
```

## Trait Conflict Resolution

When traits have methods with the same name:

```php
class MyModule implements ModuleInterface {
    use TraitA, TraitB {
        TraitA::method insteadof TraitB;  // Use TraitA's version
        TraitB::method as methodFromB;     // Alias TraitB's version
    }
}
```
